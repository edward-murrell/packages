Sambervise

Remotely administer Samba 4 Active Directory Domain Controllers from your Linux desktop. Sambervise talks to DCs over LDAP or LDAPS — nothing changes on the local machine and no local root access is needed.

  • Users: edit names and contact details, enable or disable accounts, reset passwords and set password policy
  • Groups: browse membership, add and remove members
  • Computers: view OS details and Service Principal Names, edit description and DNS host name
  • Kerberos (GSSAPI) using your existing kinit ticket, or simple bind with a password
  • Saved connection profiles, DC discovery through DNS SRV records, LDAPS and STARTTLS
$ sudo apt install sambervise
