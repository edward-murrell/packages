krbtray

A system tray application that watches every Kerberos ticket in your credential cache collection, renews them before they expire, and can re-authenticate for you using a password kept in the system keyring.

  • Tray icon shows the worst ticket state at a glance; the tooltip lists every principal and its remaining lifetime
  • Automatic renewal ahead of expiry, with a desktop notification if renewal fails
  • Per-principal menu: renew, destroy, or authenticate with a password dialog
  • Multiple principals via KCM:, DIR: or KEYRING: caches; works with Heimdal and MIT Kerberos
  • Optional password storage in GNOME Keyring or KWallet, and auto-kinit on login
$ sudo apt install krbtray
